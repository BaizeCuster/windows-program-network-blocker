# Windows 程序断网工具

一个面向 64 位 Windows 10 / 11 的开源图形工具，可按 EXE 路径创建持久化网络阻止规则。

它同时使用 Windows 防火墙程序规则和 Windows Filtering Platform（WFP）过滤规则，覆盖 IPv4 / IPv6、入站 / 出站，以及目标程序通过本机代理进行的 TCP / UDP 通信。不需要安装驱动，也不需要常驻后台。

## 下载与使用

1. 下载仓库根目录中的 `程序断网工具-v2.exe`。
2. 双击运行并允许管理员权限。
3. 选择目标 EXE，或扫描软件自己的安装目录。
4. 勾选需要限制的程序，点击“加强禁网（含本地代理）”。
5. 保存工作并完全重启目标程序。

恢复联网时，请继续使用 v2：勾选相应程序并点击“解除勾选程序禁网”。仅删除本工具或只在 `wf.msc` 删除普通规则，不能移除 WFP 加强规则。

更完整的操作说明和边界请阅读 [使用说明.txt](使用说明.txt)，测试范围见 [验证记录.txt](验证记录.txt)。

## 效果边界

- 规则按所选 EXE 路径生效；子进程、帮助程序和更新后新增或移动的 EXE 需要分别添加。
- 加强禁网也会切断目标程序的本机 TCP / UDP 通信，可能影响插件、内部协作或本地服务。
- 本工具不修改目标软件、许可证、授权服务、`hosts`、系统代理或网络适配器。
- 本工具不是进程隔离沙箱；命名管道等非网络通信不在拦截范围内。
- 目标程序若拥有管理员权限，可能自行修改过滤规则。
- 使用前请保存工作；错误选择系统程序可能导致相应程序无法联网。

## 从源码构建

源码位于 `源码` 目录。无需下载第三方依赖，构建脚本使用 Windows 自带的 .NET Framework C# 编译器生成 x64 EXE：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
& '.\源码\编译.ps1'
```

构建输出为仓库根目录的 `程序断网工具-v2.exe`。程序未进行数字签名，因此 Windows 可能显示未知发布者提示。

## 隐私与联网

程序没有遥测、广告、联网更新或其他主动网络请求。源码中使用的联网相关系统接口仅用于创建、读取和移除本机 Windows 网络过滤规则。
