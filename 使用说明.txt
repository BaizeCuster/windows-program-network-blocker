程序断网工具 v2（64 位 Windows 10 / 11）

本次修复
旧版仅使用 Windows 防火墙程序规则，未拦截普通桌面软件连接本机代理。
v2 增加按 EXE 身份匹配的 Windows Filtering Platform（WFP）过滤规则，
覆盖 IPv4 / IPv6、入站 / 出站，以及目标程序连接本机代理的 TCP / UDP 通信。
不用安装驱动，不需要常驻；规则以持久化方式保存。

使用方法
1. 双击“程序断网工具-v2.exe”，允许管理员权限。
2. 选择 EXE 或扫描软件自己的安装文件夹，检查勾选项。
3. 点击“加强禁网（含本地代理）”。状态应显示“加强禁网已就绪”。
4. 保存工作，完全退出并重新打开目标软件。
5. 恢复时，必须使用 v2：勾选程序，点击“解除勾选程序禁网”。
   此操作会移除本工具创建的普通规则和加强规则。

从旧版升级
v2 自动读取原来的普通防火墙规则。
“普通禁网（不拦本地代理）”表示该程序尚未添加加强规则。
可以勾选这些程序，再点击加强禁网。
旧版 v1 无法读取或解除新增的 WFP 加强规则。请保留 v2 用于恢复。
仅删除工具文件，或仅从 wf.msc 删除普通规则，都不会解除 WFP 加强规则。

效果边界
• 加强禁网也会切断目标程序的本机 TCP / UDP 通信，可能影响插件、内部协作或本地服务。
• 本工具按所选 EXE 路径限制连接，不会自动覆盖系统目录里的共享服务、浏览器或其他 EXE。
  子进程和帮助程序需分别添加；软件更新新增文件或改路径后需重新选择。
• 不修改软件本身、许可证、授权服务、hosts、系统代理配置或网络适配器。
  不删除缓存广告，不恢复被禁用的许可证，也不保证消除内置或已保存的授权弹窗。
• 不是进程隔离沙箱；命名管道等非网络通信不在本工具拦截范围内。
  目标程序仍可能让未被限制的其他进程代为操作；有管理员权限的程序可以修改过滤规则。
• 规则在 Windows 过滤引擎运行后生效；未设置启动早期的 boot-time 过滤。
• 其他工具创建的禁网规则会保留。因此点解除后如果仍无法联网，应检查其他已有规则。

移除
先用 v2 勾选需要恢复的程序并解除禁网，再删除本工具文件。
普通规则组：AppNetworkBlocker.7fa61582-17ca-43be-837c-d5c137df4211
WFP provider：69ba60cd-239b-4cdb-89a4-cebe927a688a
WFP sublayer：496563fc-7f1f-4a25-880e-3666bd78ebf4
最后一条规则解除后，空的 WFP provider / sublayer 元数据可能保留，不会拦截任何连接。

源码和构建
源码目录包含全部 C# 文件、管理员权限 manifest 及编译.ps1。
使用 Windows 自带 .NET Framework C# 编译器，生成 x64 EXE，无需下载依赖。
工具未签名，没有遥测、联网更新或广告。
